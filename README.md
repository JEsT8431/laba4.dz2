# Домашнее задание к работе №4

## 1. Алгоритм

1. Начало
2. Ввод данных: A — масса первого ингредиента (вводит пользователь), B — масса второго ингредиента (вводит пользователь), С — масса третьего ингредиента (вводит пользователь).
3. Условие успешного запуска реакции: реакция запускается, если масса всех трёх элементов кратна 3. 
   * *Условие запуска:* (A, В и С кратны 3).
   * В языке C это реализуется через оператор исключающего ИЛИ (XOR) или логическое неравенство: result = ((A % 3 == 0) ^ (B % 3 == 0) ^ (C % 3 == 0));
4. Вывести результат (1 — реакция пошла, 0 — реакция не пошла).
5. Конец
### Блок-схема

    Start((Начало)) --> InputA[/Ввод A/]
    InputA --> InputB[/Ввод B/]
    InputA --> InputB[/Ввод B/]  --> InputC[/Ввод C/]
    InputB --> Condition{A%3 != B%3 != C%3?}
    
    Condition -- Да --> SetResult1[result = 1]
    Condition -- Нет --> SetResult0[result = 0]
    
    SetResult1 --> Output[/Вывод result/]
    SetResult0 --> Output
    
    Output --> End((Конец))

## 2. Реализация программы
```c
#include <stdio.h>
#include <locale.h>
#define _CRT_SECURE_NO_WARNINGS

void main() {
    setlocale(LC_ALL, "RUS");
    int A, B, C, result;

    puts("Введите массу первого ингредиента (A): ");
    scanf("%d", &A);
    puts("Введите массу второго ингредиента (B): ");
    scanf("%d", &B);
    puts("Введите массу третьего ингредиента (C): ");
    scanf("%d", &C);

    result = ((A % 3 == 0) && (B % 3 == 0) && (C % 3 == 0));

    printf("Результат эксперимента (1 — реакция пошла, 0 — реакции нет): %d", result);
}
```
